# API contracts

**Status:** No API contract has been frozen yet. Microservices owns the contract when it is created. Web may review the contract and report consumer needs; it must not change this file directly.

Until an accepted contract is added here, Web uses an explicit mock/fixture and records the assumed fields and error cases next to its mock. Do not connect to an endpoint being designed in the same course week. Contract changes go through `../change-requests/index.md` and must include method, path, request/response schema, status codes, error shape, authorization, and fixture examples.
