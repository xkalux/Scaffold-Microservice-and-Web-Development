## Storage

Assign the next ID in [Change Requests](../change-requests/index.md) when a request is opened. Keep active details there or in a linked request file. On completion, store a concise record here named `NNNN-short-description.md`, for example [0001-documentation-baseline.md](0001-documentation-baseline.md). Preserve the same `CR-NNNN` in the record and index, with links in both directions.

A closed record states the request, authorized scope, resulting behavior, validation with its limits, and unresolved items or follow-up IDs. Do not store chat transcripts, repeated full docs, credentials, or runtime output already kept in an evidence file.

Archived records are reference material. Current [AGENTS.md](../../AGENTS.md) and active canonical documents govern new work. The handoff remains one replaceable current checkpoint.
