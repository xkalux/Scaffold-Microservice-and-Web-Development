# Official AI skills

This is the single project-local location for the official Elysia and Svelte skill copies. Keep upstream skill names and attribution files; do not create course-specific copies.

Keep the included Svelte MIT license and the Elysia upstream source attribution with their copies.

[skills-lock.json](../../skills-lock.json) records source paths and copied-content hashes; it does not record upstream commit SHAs. File presence does not prove agent discovery or task execution. Follow [the skill workflow](../../docs/ai-skills.md) to load only applicable files, verify the target agent's behavior, and record actual tool results. Do not silently update these copies.
